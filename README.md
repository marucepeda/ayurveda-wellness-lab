# 🌿 Ayurveda Wellness Lab

An interactive wellness planning tool that helps organize nutrition, training, recovery, and daily routines into a practical, easy-to-follow framework.

🔗 **Live site:** https://marucepeda.github.io/ayurveda-wellness-lab/

## Overview

This project consolidates personal wellness and planning frameworks into a single web page. It started as a personal tool: a 12-week nutrition and training plan adapted to winter in Argentina, with different versions for high, medium, and low energy days.

## Features

- Daily plans that adapt to energy level
- Seasonal wellness recommendations
- Nutrition and training guidance
- Easy navigation between sections
- Fallback plans for low-energy days

## Technologies

- HTML
- CSS
- AI-assisted development

## Purpose

The project explores how personal wellness knowledge can be translated into an accessible web page that supports everyday decisions and long-term habit sustainability.

## Disclaimer

This is a personal project for informational purposes only. It is not medical or nutritional advice, and it was designed for one specific person, so it may not suit you. References to Ayurveda reflect a traditional system of thought and are not backed by scientific evidence. They are used here as an organizing framework, not as medical claims.
